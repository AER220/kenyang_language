# Numbers: the audit of 25 November 2026

Diagnostics, not Kenyang to learn from. These files quote every source, including
forms nobody has confirmed, and the counting files quote Nɛpɛ́m's own replies, some of
which were built by the model and are wrong (37 and 55 in `count_21_37_55_70.txt`).
None of this may go in `knowledge_base/`.

- `numbers_1_to_100.md`: one row per number, every form found, its file and tier, and
  whether there is a recording. Marked CONFIRMED, BOOK ONLY, DISAGREED or MISSING.
- `forms_by_source_1_to_20_and_tens.txt`: the same forms for 1 to 20 and the tens,
  grouped by form.
- `count_1_to_10_five_runs.txt`: "count from 1 to 10 in Kenyang", asked five times in
  fresh sessions. Each reply in full, every passage retrieved (file, tier, the number
  forms in it), and what each number in the answer matched.
- `count_11_to_20.txt`: the same, once, for 11 to 20.
- `count_21_37_55_70.txt`: the same, once, for 21, 37, 55 and 70.

The counting runs were made on commit b67cbbd, before the numbers order in CLAUDE.md
("When sources differ") was built into the code.
