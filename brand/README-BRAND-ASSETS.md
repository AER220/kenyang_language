## Folder Structure & File Guide

### 1. `full-logo/` (Horizontal Lockup: Icon + `NƐPƐM`)
- `nepem-logo-full.svg` — Scalable vector logo for light headers. Contains named SVG groups (`#nepem-icon`, `#heart-stroke`, `#gold-leaf`, `#wordmark-nepem`) so Claude Code can animate or style parts individually.
- `nepem-logo-full-dark.svg` — Scalable vector logo for dark backgrounds (`#f4f7f5` off-white + `#dc9246` gold leaf).
- `nepem-logo-full-transparent.png` — High-res (`1920px` wide) PNG with true alpha transparency.
- `nepem-logo-full-white.png` — High-res (`1920px` wide) PNG on solid `#ffffff` background.
- `nepem-logo-full-dark.png` — High-res (`1920px` wide) transparent PNG for dark headers.
- `nepem-logo-full.webp` — Lossless WebP with alpha transparency for fast web loading.

### 2. `icon-mark/` (Standalone Heart-Leaf Symbol)
- `nepem-icon.svg` — Scalable vector symbol (light mode).
- `nepem-icon-dark.svg` — Scalable vector symbol (dark mode).
- `nepem-icon-transparent.png` — `1024x1024` square transparent PNG.
- `nepem-icon-white.png` — `1024x1024` square PNG on solid `#ffffff`.
- `nepem-icon-dark.png` — `1024x1024` square PNG on `#0d1b15` dark forest background.
- `nepem-icon.webp` — `1024x1024` lossless WebP with transparency.

### 3. `web-and-social/` (Favicons, App Icons & Social Preview)
- `favicon.ico` — Multi-resolution browser icon (`16x16`, `32x32`, `48x48`, `64x64`).
- `favicon-16x16.png` & `favicon-32x32.png` — Standard PNG favicons.
- `apple-touch-icon.png` — `180x180` iOS Safari home screen icon.
- `android-chrome-192x192.png` & `android-chrome-512x512.png` — PWA manifest icons.
- `nepem-og-social-card.png` — `1200x630` Open Graph preview card for link shares.
